1. Naturaleza del Proyecto

Mr. Rebujito es una plataforma concebida con fines estrictamente académicos. Su objetivo es la digitalización y gestión profesional de ferias andaluzas (casetas, socios, licencias y productos), sirviendo como proyecto final de para el módulo de Optativa GS, desmotrando la integración entre tecnologías de vanguardia.

2. Propiedad Intelectual

El diseño visual, la arquitectura de microservicios y el código fuente frontend han sido desarrollados por los alumnos mencionados al final de este documento. Se prohíbe el uso comercial de este software sin consentimiento expreso del equipo de desarrollo y el centro educativo.

3. Uso de Datos

Al ser un entorno de desarrollo escolar, los datos introducidos en la plataforma se consideran de prueba. El equipo no se responsabiliza de la pérdida de información o el mal uso de credenciales en este entorno académico.
